# Snake-Game-cpp
Snake Game in C++ using SDL2 and SDL_ttf.
## Files
- 'snakeg.cpp': game source code
- 'arial.ttf':font used for on screen text (keep it in the same folder as in the game)
## Requirements
A C++ compiler(MinGW/g++)
-[SDL2](https://libsdl.org)
-[SDL_ttf](https://github.com/libsdl-org/SDL_ttf)
